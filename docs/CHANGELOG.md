# Changelog

## 1.0.0

### GrandmaPhone
- Favorites-first Grandma Mode.
- Home-button routing to Favorites.
- App Switcher and Siri protection in Grandma Mode.
- Notification Center and Control Center protection while unlocked.
- Temporary Normal Admin Mode with approximately 15-minute timeout.
- Persistent Super Admin Mode without automatic timeout.
- CallKit-aware behavior for calls, including tested WhatsApp voice/video flow.
- Automatic return to Favorites after the final call ends.
- Release logging disabled.

### GrandmaClock
- Larger lock-screen time, date, and charging text.
- Larger status-bar clock.
- Dynamic width handling for enlarged time strings.
- Release logging disabled.
