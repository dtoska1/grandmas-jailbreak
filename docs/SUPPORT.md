# Support

For issues, use the GitHub repository:

https://github.com/dtoska1/grandmas-jailbreak

When reporting a problem, include:
- device model
- exact iOS version
- jailbreak and version
- package version
- whether the issue survives a respring/reboot
- whether it also occurs with the relevant tweak disabled

Do not post personal contact information, phone numbers, Apple IDs, banking information, or other sensitive data in public issues.
