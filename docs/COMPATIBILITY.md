# Compatibility

## Physically tested
- iPhone 7
- iOS 15.8.8
- Dopamine rootless
- Sileo / ElleKit

## Planned / not yet claimed
An iPhone 6s on iOS 15.x is a future target. The Home button hardware differs from the iPhone 7, so compatibility should not be advertised until the full behavior has been physically tested on that device.

Other devices, jailbreaks, and iOS versions should be considered untested unless explicitly added here.
