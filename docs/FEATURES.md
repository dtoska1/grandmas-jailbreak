# Features

## GrandmaPhone

### Grandma Mode
- Favorites-first Phone experience.
- Hides Phone tabs, Edit, add controls, and row info buttons.
- Home returns to Favorites instead of leaving the everyday user elsewhere on the phone.
- App Switcher and Siri are blocked during everyday use.
- Notification Center and Control Center are blocked while unlocked.
- Normal wake/unlock behavior is preserved.
- Cellular calls and supported CallKit calls, including WhatsApp voice/video calls, can take over normally.
- The tweak gets out of the way while a call is active.
- After the final call ends, Grandma Mode returns to Favorites.
- Reboot/respring defaults safely back to Grandma Mode.

### Normal Admin Mode
- Temporarily restores normal iPhone behavior.
- Intended for routine family maintenance.
- Automatically expires after approximately 15 minutes.

### Super Admin Mode
- Restores normal iPhone behavior without the 15-minute timeout.
- Remains active until deliberately exited.

Exact access gestures are intentionally not documented publicly.

## GrandmaClock
- Larger lock-screen time.
- Larger date.
- Larger charging-status text.
- Larger status-bar clock.
- Dynamic width adjustment prevents the enlarged clock from truncating valid time strings.
- Does not globally increase Dynamic Type.
