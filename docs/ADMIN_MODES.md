# Admin Modes

GrandmaPhone has two maintenance modes in addition to the default Grandma Mode.

## Normal Admin
Normal Admin is intended for routine maintenance: changing settings, opening apps normally, managing contacts, or performing short troubleshooting tasks. It automatically returns to Grandma Mode after approximately 15 minutes if left active.

## Super Admin
Super Admin provides the same unrestricted iPhone behavior but does not automatically time out. It stays active until deliberately exited.

## Public disclosure
The modes and their behavior are intentionally documented. The exact physical access gestures and private implementation details are not published in this repository.

## Important
Admin modes are a convenience feature, not a security boundary. Anyone with sufficient control of a jailbroken device may be able to alter or bypass software behavior.
