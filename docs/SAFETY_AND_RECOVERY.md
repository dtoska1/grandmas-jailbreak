# Safety & Recovery

GrandmaPhone is designed so that a reboot/respring returns the phone to Grandma Mode rather than leaving an unrestricted maintenance state active.

The tweaks do not replace the system telephony stack. During supported active calls, GrandmaPhone deliberately avoids forcing the Phone app back to Favorites until the call ends.

Keep a known-good copy of every release package before updating. If a new release behaves incorrectly, reinstall the previous known-good package and respring.

This project is software for a jailbroken device. It should not be treated as a security product or as a substitute for reliable emergency communication planning.
